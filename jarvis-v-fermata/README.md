# JARVIS в Fermata — шаг 1: голосовой вызов

Fermata отдаёт JARVIS голосовую фразу, которую не поняли её собственные
команды («играй», «пауза», «найди…»). JARVIS выполняет фразу своим движком
(команды телефона, звонки, «Домашка», разговор через облако или местную
модель) и возвращает ответ текстом. Fermata показывает ответ на экране
и произносит его, приостановив музыку.

Музыкальные команды Fermata работают как раньше: до JARVIS доходит только
то, что Fermata не распознала.

## Из чего состоит

| Где | Что |
|---|---|
| `android-team`, ветка `claude/jarvis-app-integration-0ewhi6` | JARVIS: вход для команд `service/ExternalCommandService.kt`, разрешение `com.jarvis.assistant.permission.KOMANDA` |
| здесь, `Fermata-2.0.2/` (изменения — в `fermata-jarvis.patch`) | Fermata 2.0.2: класс `jarvis/JarvisBridge.java`, вызов в `MainActivityDelegate.voiceSearch`, разрешение и видимость пакета JARVIS в манифесте; модуль `modules/jarvis` — вкладка JARVIS с кругом |

Обмен — через `Messenger`: запрос `1` с текстом в `tekst`, ответ `2` с текстом
в `otvet`. Числа и ключи заданы в обоих приложениях и должны совпадать.

## Вкладка JARVIS

Отдельная вкладка в нижней панели Fermata (модуль `modules/jarvis`, включена
по умолчанию). Во весь экран — круг JARVIS, тот же рисунок, что в самом
JARVIS (`ui/hud/JarvisHud.kt`), перенесённый на обычный Canvas
(`JarvisHudView`, математика — `HudMath`).

- Касание круга или плавающей кнопки с микрофоном — сказать фразу. Кнопка
  «Активировать голосовое управление» (например, на руле), пока открыта
  вкладка, делает то же.
- Фразу сначала выполняет Fermata («пауза», «играй…»), непонятую получает
  JARVIS — как при обычном голосовом поиске.
- Фазы круга: «Слушаю…» с эквалайзером по громкости микрофона → «Думаю…» со
  сканирующим лучом, пока ждём JARVIS → пульсация, пока Fermata произносит
  ответ. Под кругом ничего не показывается, ответ только звучит.
- Музыка на паузе от начала записи до конца ответа, потом возобновляется.

Запуск по слову «Джарвис» внутри вкладки — следующим шагом.

## Защита входа

Отдавать команды JARVIS может только приложение, которому пользователь сам
выдал разрешение «команды для JARVIS» в системном диалоге. Разрешение
проверяется дважды: системой при привязке к сервису и самим JARVIS по
отправителю каждого сообщения. Фраза длиннее 500 знаков отклоняется.

## Как собрать и поставить

Fermata 2.0.2 уже лежит в репозитории распакованной (`Fermata-2.0.2/`),
патч `fermata-jarvis.patch` на неё наложен — распаковывать и накладывать
ничего не нужно. Сам патч оставлен здесь как запись изменений относительно
исходной Fermata 2.0.2.

1. Собрать Fermata из `Fermata-2.0.2/` по её README (вариант `auto` или `mobile`).
2. Собрать JARVIS из ветки `claude/jarvis-app-integration-0ewhi6` репозитория
   `android-team` (номер сборки — по `nomer-sborki.txt`).
3. **Сначала поставить JARVIS, потом Fermata.** Разрешение объявляет JARVIS;
   если Fermata стоит раньше, система не даст его выдать — тогда Fermata
   нужно переустановить.
4. В Fermata открыть вкладку JARVIS, коснуться круга и сказать фразу,
   которую Fermata не знает, например «сколько заряда». При первом
   обращении Fermata спросит доступ к микрофону и разрешение «команды для
   JARVIS» — разрешить.

## Не проверено

Проверено в облаке: сборка, модульные тесты математики круга (11), вид круга
в фазах — снимками Robolectric.

- Сборка обоих приложений: в среде, где писался код, нет Android SDK.
  Патч проверен только на то, что чисто ложится на Fermata 2.0.2 (наложен без отказов).
- Работа на телефоне: разрешение, привязка, ответ голосом.
- В машине: голос Fermata в Android Auto идёт тем же путём (`voiceSearch`),
  но системный диалог разрешения там не покажется — разрешение нужно выдать
  заранее на телефоне.

## Fermata в Android Auto — как заработало (16.10.2026)

Fermata Auto, Fermata Mirror и Fermata Media Service появились в «Настроить
панель запуска» Android Auto 17.8 (Redmi 10C, Android 13), когда сошлись два
условия:

1. **Своё имя пакета.** Сборка с `-PAPP_ID_SFX=.lichnaya` →
   `me.aap.fermata.auto.lichnaya` (так велит README Fermata). С именем по
   умолчанию `me.aap.fermata.auto` Android Auto отсеивал приложение при любой
   установке — видимо, оно в серверном чёрном списке.
2. **Установка через KingInstaller на пустое место** (не обновлением): в
   `/data/system/packages.xml` установщик `com.android.vending`, инициатор
   `com.google.android.packageinstaller`. Так проверяет Android Auto 17.7+ —
   разбор https://github.com/AndreyPavlenko/Fermata/discussions/847

Что не нужно и не помогает: «системное приложение» (модуль `magisk-fermata`
оставлен для истории), перенос Lucky Patcher, пометка установщика через
`pm install -i` (инициатором пишется оболочка), LSPosed. Каждое обновление
Fermata — так же, через KingInstaller.
